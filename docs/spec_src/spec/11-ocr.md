# 11. В планах: OCR

[← К оглавлению](../BACKEND_SPEC.md)

> **[ПЛАНЫ] — сейчас делать не обязательно.** Но поля и флаги ниже **уже входят в контракт**: бэк принимает их в результате ML (они необязательные), хранит и отдаёт; фронт может их игнорировать, пока OCR нет. Тогда переход не потребует менять схемы.

## 11.1. Зачем

Часть статей — сканы или PDF без текстового слоя (старые журналы, отсканированные отчёты, диссертации). Для них текст, таблицы и подписи нужно сначала распознать (OCR), а уже потом извлекать значения. Сейчас такие файлы получают `processing.failed` с кодом `pdf_no_text` («В PDF нет текста — распознавание сканов пока не поддерживается»).

## 11.2. Где OCR стоит в конвейере

```
Загрузка [BE] → Проверка, нужен ли OCR [BE] → OCR [ML/OCR-сервис] → Разметка (A2) → Извлечение (A3–A8) [ML] → Нормализация [BE] → Проверки [BE]
                                                  ↑ только для страниц-сканов
```
OCR — **перед извлечением**, постранично: страницы с нормальным текстовым слоем идут как есть, сканы — через OCR. Делает его ML-сервис (тот же или отдельный OCR-сервис за ним); для бэка это одна задача `MlJob` с `options.ocr`. На экране этап «Текст» показывается как «Распознавание текста» для статей с OCR.

## 11.3. Как бэк определяет, что OCR нужен [BE]

При загрузке, до постановки задачи ML, бэк для каждой страницы считает:
- есть ли текстовый слой и сколько в нём символов;
- доля площади страницы, занятая изображениями;
- доля «мусорных» символов (неизвестные глифы, `�`, символы из Private Use Area — признак битой кодировки шрифтов).

Страница — **скан**, если текста < 100 символов и изображение занимает > 70 % площади, **или** мусорных символов > 30 %. Список таких страниц уходит в задачу: `options.ocr = "auto"` и `options.ocr_pages = [1, 2, 5]`. Если сканов > 0 — `paper.ocr.needed = true`. Режимы `options.ocr`: `off` (не распознавать — сканы пропускаются с `warning`), `auto` (только сканы, по умолчанию), `force` (все страницы — для битых шрифтов).

## 11.4. Новые поля

### В артефактах ML (§7.2) — необязательные
| Где | Поле | Тип | Описание |
|---|---|---|---|
| A2 `pages[]` | `ocr_used` | bool | страница распознана OCR |
| A2 `pages[]` | `ocr_confidence` | number 0..1 | средняя уверенность распознавания страницы |
| A2 `pages[]` | `ocr_language` | string[] | языки распознавания (`["ru", "en"]`) |
| A2 `pages[]` | `rotation`, `dpi`, `deskew_deg` | int, int, number | поворот, разрешение, выравнивание |
| A2 `pages[]` | `words` | `[{text, bbox, confidence}]` | слова с bbox — текстовый слой для выделения мышью |
| A2 `blocks[]` | `ocr_confidence` | number | |
| A2 `tables[].cells[]` | `ocr_confidence` | number | уверенность распознавания ячейки |
| `Place` | `ocr_confidence` | number | уверенность распознавания текста под bbox значения |
| конверт | `ocr` | `{used, engine, engine_version, pages:[n], mean_confidence}` | сводка |

### В модели бэка
| Сущность | Поле | Ист. | Описание |
|---|---|---|---|
| `Paper` | `ocr` | [BE]/[ML] | `{needed: bool, used: bool, pages: [1,2,5], mean_confidence: 0.91, engine: "…"}` |
| `Page` | `ocr_used`, `ocr_confidence`, `ocr_language` | [ML] | |
| `Anchor` | `ocr_confidence` | [ML] | |
| `Fact` | `ocr_used` | [BE] | значение взято со страницы-скана |
| `Fact` | `ocr_confidence` | [ML] | уверенность распознавания символов значения (отдельно от `confidence` — уверенности извлечения) |
| `Fact` | `confidence` | [BE] | для OCR-значений бэк хранит исходную уверенность извлечения, а для сортировки «надёжных» использует `min(confidence, ocr_confidence)` |

Новое правило проверки (§5): `ocr_low_confidence` — `ocr_confidence < 0,8` у числового значения → `warn` / `doubt` «Значение распознано со скана неуверенно: проверьте цифры». Такие факты не попадают в «Принять надёжные».

Отчёт точности (`/checks/accuracy`) — разрез `by_ocr` (скан / текст).

## 11.5. Как фронт показывает

- В шапке статьи — пометка «Скан, распознано» с подсказкой «N страниц распознаны с изображения, средняя уверенность 91 %».
- На странице-скане PDF — изображение страницы, поверх — невидимый текстовый слой из `words` (чтобы выделение мышью и ручное добавление работали).
- У факта со скана в строке источника — значок «скан» рядом с «т. 2 · стр. 4»; в карточке «Подробнее» — строка «Распознано со скана: уверенность 76 %».
- Низкая уверенность (`ocr_confidence < 0,8`): значение подчёркнуто пунктиром янтарного цвета, замечание `ocr_low_confidence` в списке, факт исключён из «Принять надёжные». При наведении — подсветка bbox значения на изображении, чтобы человек сверил цифры глазами.
- В экспорте — колонка `ocr_used` (в реляционном JSON — поле факта).

## 11.6. Ошибки
| Код | Когда |
|---|---|
| `pdf_no_text` | OCR выключен, а страниц-сканов > 50 % |
| `ocr_failed` | OCR не справился (качество скана) — статья `failed`, «Не удалось распознать скан: попробуйте файл лучшего качества» |
| `ocr_partial` | часть страниц не распознана — `warning`, замечание `info` |
