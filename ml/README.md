# ml/ — временная копия прототипа ML-1

`pdf-dataset/` — прототип сервиса извлечения Ивана (ML-1): PDF → glmocr → markdown → RouterAI → 7 таблиц.
Лежит здесь как **заплатка**, чтобы бэкенд и фронт работали на настоящем извлечении, пока Иван переделывает сервис.
Владелец кода — Иван; когда придёт новая версия, папку заменяем целиком.

Наши правки помечены `[faktura-patch]`:
- `api.py` — `/extract` обычным `def` + блокировка: `/health` отвечает во время разбора, разборы строго по одному;
- `Dockerfile` — torch CPU-сборкой (без CUDA-библиотек).

Бэкенд ходит в него с `FAKTURA_EXTRACT_PROTOCOL=pdf_dataset` (переходник формата ответа и имён колонок —
`backend/src/faktura/ml/`). Деплой: `bash backend/deploy/deploy.sh --ml`, включение — блок «ML-1 прототип» в `deploy/.env`.
